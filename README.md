# Mocktail Menu

I made this website with React to show non-alcoholic drinks. It gets the drink names, pictures, and recipes from TheCocktailDB. You can search for drinks and save the ones you like.

## Run the project

1. Install the packages with `npm install`.
2. Start the project with `npm run dev`.

## Pages

- `/` - Home page
- `/drinks` - Drinks menu and search
- `/drinks/:id` - Drink recipe
- `/favourites` - Saved drinks
